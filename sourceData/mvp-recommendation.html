MVP Recommendation

Advisor AI Copilot — What to Build First

Demo lens: Advisor Productivity (time reclaimed per workflow)
Recommendation

Lead with 3 features, defer 2 to Phase 2

For a productivity-focused demo, you want a tight loop that leadership can see in under 10 minutes: upload a plan, get a brief, prep a meeting, capture the follow-up. The Client Q&A Copilot and full Compliance Assistant are high-value but carry technical and regulatory risk that slows MVP delivery without strengthening the demo narrative. Include them as a "coming next" slide — not the headline.

MVP CORE Ship These Three — They Tell One Story
Together these cover the full arc of a client interaction: prepare → meet → follow up. One workflow, three time savings, one demo.
1. Financial Plan Summarization Saves 45 min/plan
Agent ingests a 40–80 page plan PDF, produces a 2-page client-ready summary (goals, gaps, next steps) + a separate advisor-facing action checklist. Generates both a "what changed since last review" delta and a full summary.
Data:
Planning PDFs (MoneyGuide, eMoney, RightCapital)
MCP:
Document store connector, planning software API
This IS the Cyan headline. If you build nothing else, build this. Immediately recognizable to any advisor. The before/after is visceral — 60-page PDF vs. 2-page brief.
2. Meeting Prep Brief Generator Saves 30 min/meeting
Agent pulls data from CRM + custodian, assembles a one-pager: portfolio snapshot, performance vs. benchmark, recent transactions, life events flagged, suggested talking points based on plan gaps and market context.
Data:
CRM (Salesforce/Redtail), custodian feeds, calendar, prior meeting notes
MCP:
CRM connector, custodian API, calendar API
The highest-frequency use case. Advisors do 6–12 meetings/week. Multiply 30 min saved x 8 meetings = 4 hours/week reclaimed. Easy to demo with real-looking data.
3. Research Digest Agent Saves 20 min/day
Agent monitors fund fact sheets, product updates, and market commentary; matches changes to the advisor's book of business; surfaces a daily brief: "3 things that changed yesterday that matter for your clients."
Data:
Fund prospectuses, Morningstar data, custodian product shelf, research feeds
MCP:
Market data connector, document parser, portfolio holdings API
Demonstrates ongoing, ambient intelligence — the copilot works even when the advisor isn't asking. Shows the agent is proactive, not just reactive. Strong "morning briefing" demo moment.
PHASE 2 Queue for Next Sprint — High Value, Higher Complexity
These are powerful but carry either technical depth (real-time inference) or regulatory surface area (compliance language) that would slow down the first demo without proportional payoff.
4. Client Q&A Copilot (Real-time) Saves 15 min/meeting
During a meeting, advisor asks the copilot "what if" questions ("What if we delay Social Security to 70?") and gets instant answers grounded in the client's actual plan data.
Data:
Financial plan models, tax projections, Social Security tables, portfolio analytics
MCP:
Planning engine API, tax calculator, market data
Risk: Requires low-latency RAG over client-specific data with high accuracy. A wrong number in a live meeting is worse than no number. Needs robust grounding and confidence scoring before it's demo-safe.
5. Compliance Documentation Assistant Saves 25 min/trade
Auto-drafts suitability memos, trade rationale notes, and disclosure summaries from trade context + client profile. Pre-populates with firm-specific compliance templates and regulatory language.
Data:
Trade blotter, client risk profiles, IPS, regulatory templates, firm compliance guidelines
MCP:
OMS connector, compliance template store, CRM
Risk: Compliance language must be precise. Regulatory exposure if auto-generated text is used without adequate review workflow. Needs firm-specific template validation and a human-in-the-loop approval gate. Better as Phase 2 once the review UX is proven.

MCP Integration Architecture (MVP)

  • Document IngestionMCP server for PDF parsing (plans, prospectuses, fact sheets) — structured extraction via layout-aware models
  • CRM ConnectorMCP server for Salesforce/Redtail — read client profiles, notes, tasks, life events, meeting history
  • Custodian DataMCP server for portfolio holdings, performance, transactions (Schwab/Fidelity/Pershing APIs)
  • Market/ResearchMCP server for fund data feeds, Morningstar analytics, research note ingestion
  • Output LayerAgent generates structured JSON → rendered as branded briefs, summaries, and action lists in advisor UI
  • GuardrailsAll outputs are advisor-facing drafts — never auto-sent to clients. Human-in-the-loop by design.

Why Defer Q&A Copilot and Compliance to Phase 2

  • Q&A CopilotReal-time inference needs sub-2s latency, high numerical accuracy, and confidence scoring. A wrong projection shown live to a client (or in a demo) is a credibility risk. Better to prove the data layer works in Phases 1 briefs before exposing it interactively.
  • Compliance Asst.Regulatory language is zero-tolerance for errors. Firms need to validate templates, build approval workflows, and potentially get legal sign-off. High value once the platform is trusted — but premature as the first thing leadership sees.
  • Demo narrativeThree features tell one clean story (prepare → brief → follow up). Five features dilute the demo into a feature tour. Constraint makes the pitch sharper.
